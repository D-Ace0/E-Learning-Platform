# 🎓 E-Learning Platform

A full-stack E-Learning Platform built to provide an interactive online learning experience for both students and instructors.

The platform includes user authentication, course management, enrollment, video-based learning, progress tracking, and an admin dashboard for managing the system.

---

## 🚀 Features

### 👨‍🎓 Student

* User Registration & Login
* Secure Authentication
* Browse Available Courses
* Enroll in Courses
* Watch Course Content
* Track Learning Progress
* Responsive User Dashboard

### 👨‍🏫 Instructor

* Create Courses
* Update Course Information
* Upload Course Content
* Manage Students

### 👨‍💼 Admin

* Manage Users
* Manage Courses
* Manage Categories
* View Platform Statistics
* Administrative Dashboard

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/D-Ace0/E-Learning-Platform.git

cd E-Learning-Platform
```

---

### Backend

```bash
cd backend

npm install

npm run start:dev
```

---

### Frontend

```bash
cd frontend

npm install

npm run dev
```
